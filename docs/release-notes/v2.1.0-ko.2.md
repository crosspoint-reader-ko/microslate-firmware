MicroSlate 2.1.0 Korean, fix release.

## Changes

- Main menu: the key hint and keyboard status lines no longer overlap. They were 16 px apart, which the Korean UI font no longer fits, so the two lines collided in both English and Korean.

## Files

| File | Use |
|---|---|
| `dualboot-ko-<tag>.bin` | CrossPoint (Korean) + MicroSlate. Flash at `0x0`. Erases settings and Bluetooth pairing. |
| `microslate-<tag>-app.bin` | MicroSlate app only. Flash at `0x6B0000` on a device that already has the Korean CrossPoint layout. Keeps settings. |
| `microslate-<tag>.bin` | MicroSlate alone (upstream layout). Flash at `0x0`. |

The easiest way to install or update is the web flasher at https://crosspoint.kr/flasher.
