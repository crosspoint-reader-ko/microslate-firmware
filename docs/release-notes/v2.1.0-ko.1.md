MicroSlate 2.1.0 with Korean input and a Korean UI, plus a dual-boot image with the Korean CrossPoint fork.

## Changes

- Korean (Dubeolsik) input with the RIDI Batang font (12/14/16pt, SIL OFL 1.1).
- Toggle Korean/English with Shift+Space. The Han/Yeong (LANG1) key, Ctrl+Space and a Right Alt/Cmd tap also work.
- Settings > Language: English / 한국어. The default is English.
- On a dual boot, MicroSlate registers itself as "MicroSlate (한글)", and CrossPoint shows it under Home > 앱. Selecting it restarts into MicroSlate.

## Files

| File | Use |
|---|---|
| `dualboot-ko-<tag>.bin` | CrossPoint (Korean) + MicroSlate. Flash at `0x0`. Erases settings and Bluetooth pairing. |
| `microslate-<tag>-app.bin` | MicroSlate app only. Flash at `0x6B0000` on a device that already has the Korean CrossPoint layout. Keeps settings. |
| `microslate-<tag>.bin` | MicroSlate alone (upstream layout). Flash at `0x0`. |

```bash
esptool.py --chip esp32c3 write_flash 0x0 dualboot-ko-<tag>.bin
# or, keeping CrossPoint settings:
esptool.py --chip esp32c3 write_flash 0x6B0000 microslate-<tag>-app.bin
```

While MicroSlate is in the second slot, CrossPoint's OTA and SD firmware updates are blocked, so they can't overwrite it.
